QUICK GUIDE

Import now. Organize when you’re ready.

  1. 1. Add a source

    Open Sources and paste a YouTube video or playlist. Monitor a playlist to import new additions.

  2. 2. Listen in Navidrome

    Downloaded songs appear in Waiting for approval and their playlists after Navidrome scans your library.

  3. 3. Review the metadata

    Choose a suggested match and Approve, search MusicBrainz, or keep the original source tags. The approved file replaces the temporary copy.

From import to approval

Follow the numbered steps for the usual path. The sections below explain retries, stopped downloads and other transitions.

  1. QueuedWaiting for the worker
  2. ProcessingDownload and identify
  3. Waiting for approvalListen and review the metadata
  4. Apply and finishApproval queues the worker again; success leaves the track idle

Temporary problem

Processing → Deferred → Processing

The displayed retry time controls the next attempt. A shared YouTube pause can also move queued work directly to Deferred. Repeated download failures eventually need your attention.

Source cannot be downloaded

Download work → Stopped

Use Stop retrying this URL, or let a restricted-video error stop it automatically. Choose another URL, or enable the old one before retrying. Existing audio stays playable.

Operation failed

Processing → Failed → Queued

Read the error and choose Retry. A failed replacement keeps existing audio playable.

Update existing music

Idle → Queued → Processing

Reprocess, Redownload and metadata edits start a new operation. The worker asks for review when a match needs your decision.

What do the statuses mean?

Two independent states: audio tells you whether a file is playable; the operation tells you what the app is doing.

Playable / AVAILABLE
A local file is available, including temporary audio.
Missing / MISSING
A file expected in your library is missing. Use Redownload.
No audio / UNAVAILABLE
No file has been downloaded. Spotify-only entries need Link audio.
Queued / QUEUED
The worker will start when earlier jobs finish.
Processing / RUNNING
A download or metadata operation is running.
Waiting / NEEDS_APPROVAL
Review the suggested metadata, search for another match, or use source tags.
Deferred / DEFERRED
A provider is temporarily unavailable. Wait for the displayed retry time.
Stopped / STOPPED
Downloads were stopped. Choose another URL, or enable the source and retry. Existing audio is kept.
Failed / FAILED
Open the error, fix the cause if needed, then Retry.
Idle / IDLE
No operation is running. Temporary audio remains marked until its metadata is approved.
Fix a wrong match or separate different songs

Use Review metadata to search MusicBrainz by artist and title, or choose Original source metadata to undo a wrong match.

If different uploads were merged, open Sources & details → Separate track on the wrong URL. Its playlist memberships follow the new entry, its audio is queued, and the rejected match is excluded from future suggestions.

The source of the current audio is protected. First Reprocess using the correct URL, then separate the other one. Remove & ignore origin instead excludes only that URL from future imports.

Spotify imports and connection setup

Spotify supplies track names and playlists. Connect your account in Sources, then use Link audio to choose an existing recording or import a YouTube video. Spotify does not supply downloadable audio.

Connection setup and Spotify access limits

Create an app in the Spotify Developer Dashboard. Set SPOTIFY_CLIENT_ID and SPOTIFY_REDIRECT_URI in your server environment, then restart. A client secret is not required.

Register this exact callback: https://YOUR-INGESTOR-HOST/api/spotify/callback

Use HTTPS, or HTTP with an explicit loopback IP for local development. Spotify does not accept localhost. Development-mode apps require an eligible Premium app owner and allowlisted users. Playlist contents are available only for playlists you own or collaborate on.

This is read-only access. Music Ingestor does not modify your Spotify library. Each library user connects separately; keep this administration interface behind authentication.

Playback, discovery dates and administration

Navidrome sees changes on its next library scan. Temporary songs use the album Waiting for approval; approval moves them to their chosen album and updates exported playlists.

Discovery dates come from playlist additions or the first time a track was seen. They are saved in COMMENT and DESCRIPTION, separately from release dates.

Enable track ReplayGain in your player to use the measured loudness tags. Tag repair does not re-encode audio.

Each library user has separate files and playlists. These folders are not authentication: keep this administration app behind an authenticated reverse proxy.
